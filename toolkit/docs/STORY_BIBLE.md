# 《星屑放课后》设定集 & 剧情圣经

> 写剧本前先读 `docs/SCRIPT_FORMAT.md`（`.nls` 格式规范）和本文件。

## 1. 一句话

废部倒计时三十天，只剩一个人的天文社，和三个把心愿寄放在星空里的女孩。
夏天结束的时候，你必须决定——**把望远镜对准谁。**

## 2. 世界观与基调

* 舞台：私立青岚高中。靠海的坡道小城，光害少。当地传说：「星见祭的夜里向流星许愿，愿望会被记在星图上。」
* 时间：四月开学 → 七月「星见祭」（学园祭 + 流星雨观测会）。
* 基调：**温柔、清爽、带一点苦涩的夏日青春**。不是催泪剧也不是搞笑番，是「很久以后还会想起来」的那种质感。
* 幻想浓度：**零**。没有超能力、没有穿越。所有奇迹都是人与人之间发生的事，星空只是他们把话说出口的借口。
* 叙事人称：第一人称（主角星野悠的视角）。旁白 `*` 与主角台词都是他的视角。
* 每场戏要有具体的**触感细节**：蝉鸣、粉笔灰、冰镇可乐罐上的水珠、风扇转动的咔嗒声、海风里的盐味。
* 节奏：一场戏 60～140 行；不要连续超过 6 行纯风景；每 8～12 行至少一个笑点或情绪转折。

## 3. 角色与说话方式

### 星野 悠（剧本里写 `悠`）—— 主角
高二。天文社最后一名社员。话不多，观察力好，认死理。用「嗯」「……大概吧」掩饰自己其实很在意。
口头禅：`「……大概吧。」`／`「我只是想再看一会儿。」`

### 白石 遥（`遥`）—— 青梅竹马 / 田径部王牌
亚麻色短发 + 侧边蝴蝶结发夹，蜜色皮肤，笑起来毫无保留。
**大声、直率、先跑起来再说**；会替别人生气，不会替自己难过。
隐藏面：右膝旧伤，一直没说，因为「说了就会有人替我放弃」。
说话方式：短句、感叹号多、拖长音的「诶——」「呐呐」。被戳到心事时突然安静，用「……没什么。」结尾。
> `遥: 呐，{name}，你发呆的时候，嘴角会往下掉一点点哦。`

### 冬月 澪（`澪`）—— 转学生 / 图书委员
黑色长直发、紫眼睛、皮肤很白，校服一丝不苟，总抱着借书卡快写满的旧书，左眼下有一颗小泪痣。
**冷淡、毒舌、说话带刺但从不撒谎**，用书本当盾牌，讨厌被同情。
隐藏面：在找一颗「目录上有、但没人真正拍到过」的星（观测记录 No.13）。母亲是研究员，长年在国外观测站。
说话方式：书面语、比喻多、爱用天文学词汇（视星等、赤经、光年、绝对星等）。挑衅时尾音上扬：「——你确定？」
> `澪: 人类仰望星空的理由只有一个：想知道自己有多渺小。你不觉得这很奢侈吗。`

### 神代 灯里（`灯里`）—— 学生会长 / 完美优等生
深栗色长发低马尾，细框眼镜（只在看书时），制服笔挺，胸前的会长徽章擦得很亮。
**温柔、得体、滴水不漏**，永远说正确的话，永远在对的时间微笑。
隐藏面：家里已经替她填好志愿表（医学部）；她做的每件事都要写进履历。她非常不擅长说「我想要」。
说话方式：敬语、条理清楚、「——那么」「请允许我」。累到极限时会突然用极小的声音说真心话，然后立刻道歉。
> `灯里: 星野同学，社团存续申请的截止日期是六月三十日。这是规则，不是我的意愿。`

### 小暮 智也（`智也`）—— 死党 / 吐槽役
同班，棒球部替补。负责说「你小子，别装傻」，调节气氛。

### 萩原 玲子（`萩原`）—— 天文社顾问老师
教物理，三十岁上下，戴眼镜，说话慢悠悠但关键处很锐利。她从不让主角替她做决定，只说：「望远镜不会替你看星星。」

## 4. 主线机制

* 共通线有**三天的自由行动**：第 1 / 2 / 3 天，玩家选跟谁在一起。玩家选择分别写进布尔变量 `d1_haruka` / `d1_mio` / `d1_akari` …（每场里再给一个 `@set d#_x_close = true` 表示「更靠近她」）。
* 星见祭当夜最后一个选择：**把望远镜对准谁** → 四个选项直接跳到 `rt_haruka` / `rt_mio` / `rt_akari` / `rt_alone`。
* 每条线内部再用 `@if <布尔变量>` 分岔成 **GOOD END** 与 **NORMAL END**。

## 6. 风格样例（照这个手感写）

```
* 天文台的铁门总是在下午四点十七分响。
* 不是钟声——是海风把门缝里的锈吹得发抖。
悠: ……我知道。
萩原|smile: 那你为什么还擦？
* 因为不擦的话，我就没有别的地方可以待。
遥: 呐，{name}。你有没有想过，星星其实一直在白天也在？
悠: 嗯。
遥|laugh: 那我们来证明它。
```

要点：
1. 用**具体的数字和时间**（四点十七分、第十三次、六百二十日元）。
2. 情绪不要直接说，用动作和物件代替（「她把可乐罐捏出一个凹痕」而不是「她很动摇」）。
3. 每场戏结尾留一个钩子。
4. 台词口语化，角色必须靠台词本身就能分辨出是谁。

## 7. 禁忌

1. 不用白名单以外的 pose / bg / bgm / 角色名 / 变量名。
2. 不写 R18、不写违法内容、不写自伤细节；保持全年龄。
3. 不写超自然设定；不写他人作品的角色名或梗。
4. 不重复定义同名场景 id。
5. 称呼：遥叫主角「{name}」（生气时连名带姓「星野」），澪叫「星野同学」，灯里叫「星野同学」，智也叫「{name}」或「喂」，萩原叫「星野」。
6. **不要**在 `@choice` 里混用带 `->` 和不带 `->` 的选项。
